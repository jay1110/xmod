# Xmod documentation

Xmod extends Wolfenstein: Enemy Territory with gameplay settings, persistent
player records, administration, Lua scripting and Omni-bot support.

Start with the server setup guide when installing or updating a release.
Antirush and VPN administration have dedicated guides in English and German.
The command and cvar references are generated from the documentation and code
in the same checkout as this site.

## Deutsch

Die Server-Anleitung erklärt Installation, Konfigurationsreihenfolge und private
Zugangsdaten. Antirush und VPN-Blocker sind jeweils auf Englisch und Deutsch
dokumentiert. Die Befehls- und Cvar-Referenzen werden bei jedem Dokumentationsbuild
aus diesem Projekt erzeugt; die Suche umfasst auch diese Referenzseiten.
